# Data Duplication Removal Using Machine Learning

A machine learning approach to detect and remove duplicate records in datasets, improving storage efficiency and data quality.

## Abstract
In computing, data deduplication eliminates duplicate copies of repeating data. This project uses ML techniques — including Support Vector Machines and Alternating Decision Trees — to classify record pairs as duplicates or not, based on similarity scores derived from multiple features.

## Key Features
- Duplicate detection using SVM and ADTree classifiers
- Feature vectors combining multiple similarity scores
- Scalable to large collections via blocking/filtering techniques
- Reduces storage and network transfer overhead
